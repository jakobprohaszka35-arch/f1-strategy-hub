# F1 Strategy Hub

Setup files of **F1 Strategy Hub**, the strategy tool for F1 25 and the 2026 Season Pack: race packs from the Discord track message, live overlays and telemetry.

The app checks the latest release here at startup and can update itself (**Update now**). Your packs, sessions and settings stay.

- Download page, description and updates: [Overtake](https://www.overtake.gg/downloads/f1-25-f1-26-strategy-tool-%E2%80%93-race-packs-live-overlay-telemetry.88218/)
- Manual install: download `F1.Strategy.Hub.Setup.<version>.exe` from the [latest release](../../releases/latest) and run it.
